# ⚓ Морской бой

Простая браузерная игра **«Морской бой»**, разработанная с использованием HTML, CSS и JavaScript.

## 🎮 О игре

**«Морской бой»** — классическая игра, в которой игрок должен найти и уничтожить все корабли противника раньше, чем противник уничтожит его флот.

В игре есть:

* игровое поле игрока;
* игровое поле противника;
* автоматическая расстановка кораблей;
* возможность стрелять по кораблям противника;
* компьютерный противник;
* определение попаданий и промахов;
* определение уничтоженных кораблей;
* звуковые эффекты;
* кнопка начала новой игры;
* анимации попаданий и взрывов.

## 🛠️ Используемые технологии

* **HTML5** — структура страницы
* **CSS3** — оформление, стили и анимации
* **JavaScript** — игровая логика и взаимодействие
* **Web Audio API** — звуковые эффекты

## 🚢 Корабли

В игре используется **5 кораблей**:

| Корабль           |   Размер | Количество |
| ----------------- | -------: | ---------: |
| Большой корабль   | 3 клетки |          1 |
| Средний корабль   | 2 клетки |          2 |
| Маленький корабль | 1 клетка |          2 |

Размер игрового поля — **8 × 8 клеток**.

## ▶️ Как запустить игру

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Откройте файл `index.html` в браузере.
4. Нажмите **«⚓ Новая игра»**.

Дополнительная установка или библиотеки не требуются.

## 🎯 Как играть

1. Корабли игрока автоматически размещаются на поле.
2. Нажмите на клетку на поле противника, чтобы сделать выстрел.
3. 🔥 — попадание.
4. 🌊 — промах.
5. После хода игрока компьютер делает свой ход.
6. Чтобы победить, необходимо уничтожить все корабли противника.
